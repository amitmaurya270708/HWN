# Code of Conduct

## Our Pledge

We want **HWN — Hand Written Notes** to be a welcoming, respectful, and constructive project for everyone.

Contributors, maintainers, and community members are expected to participate in a way that supports a positive environment.

## Expected Behavior

Examples of positive behavior include:

- Being respectful and considerate.
- Giving constructive feedback.
- Focusing on ideas and technical issues rather than individuals.
- Welcoming people with different levels of experience.
- Accepting reasonable corrections and feedback.
- Helping keep discussions useful and on topic.
- Respecting project, copyright, and licensing requirements.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, threats, or personal attacks.
- Discrimination or hateful conduct.
- Sexual harassment or inappropriate sexual content directed at others.
- Trolling, deliberate disruption, or repeated bad-faith behavior.
- Publishing private or sensitive information about others without permission.
- Impersonation or deliberate deception.
- Uploading malicious files, malware, or intentionally harmful code.
- Any other conduct that would reasonably make the project unsafe or hostile for participants.

## Content and Copyright

Contributors must respect intellectual property rights.

Do not submit copyrighted notes, books, scans, images, PDFs, or other material unless you have the necessary permission or the material is appropriately licensed for redistribution.

If a contribution appears to violate copyright or another person's rights, maintainers may remove it.

## Enforcement

Project maintainers may remove, edit, reject, or restrict contributions or participation that violates this Code of Conduct.

Enforcement decisions should be made fairly and proportionately to the behavior involved.

## Reporting

If you experience or witness unacceptable behavior related to the project, report it privately to the project maintainer through an appropriate GitHub communication channel.

When reporting an issue, provide enough context for the maintainer to understand what happened. Avoid publicly posting private information.

## Scope

This Code of Conduct applies to project spaces and interactions related to HWN, including:

- GitHub issues
- Pull requests
- Code reviews
- Discussions
- Project-related communication
- Other spaces when someone is representing the project

## Attribution

This Code of Conduct is inspired by widely used open-source community standards, including the Contributor Covenant.

The project may adapt these guidelines as the community grows.
